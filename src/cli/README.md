# src/cli — офлайн-режим (етап 5)

Тут буде CLI-харнес. Він використовує те саме ядро (`src/core`), що й GitHub Action.

Що він робитиме:

1. Читати розмічений датасет з `datasets/` (JSON або YAML).
2. Проганяти кожну рекомендацію через оцінювачі.
3. Порівнювати оцінку довіри з міткою людини.
4. Рахувати метрики: Precision, Recall, F1, Accuracy, Brier Score.
5. Будувати діаграму калібрування і робити ablation (вимикати оцінювачі по одному).
